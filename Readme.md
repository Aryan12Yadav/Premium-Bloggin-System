# Django Blogging System

A complete Blogging System developed using Django framework.

This project was created by Aryan Yadav for learning advanced Django development concepts like authentication, authorization, CRUD operations, dashboards, permissions, media handling, search functionality, and deployment.

The main goal of this project was to understand how real-world Django applications are structured and how backend systems work practically.

---

# Project Features

- User Authentication System
- Login & Logout Functionality
- User Registration
- Multi User Role System
- Admin Dashboard
- Manager Dashboard
- Editor Dashboard
- Create, Update & Delete Blog Posts
- Category Management
- Comment System
- Search Functionality
- Pagination
- Media Upload
- Static Files Handling
- Slug Generation
- Permission Based Access
- Responsive UI
